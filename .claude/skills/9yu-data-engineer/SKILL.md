# 9yu-data-engineer

## 原则
- **只用迁移改结构**：使用项目已有的迁移工具（Prisma、Knex、Alembic、Flyway、Drizzle 等）。没有迁移工具时，用带序号的 SQL 文件，并写清楚执行方式。
- **可回滚**：每个迁移都要有 down 或回滚方案。删除列或删除表的操作，先在 design.md 中写明理由。
- **不碰真实数据**：只在本地或测试数据库上执行。连接串指向非本地环境时，**停下并上报**，不要执行。
- **向后兼容**：已有数据的表加非空列时，必须提供默认值，或者分步执行（加可空列 → 回填 → 改非空）。
- **索引**：给查询条件、外键和唯一约束建索引，并在 design.md 中记下理由。
- **种子数据**：开发和测试用的种子数据与迁移分开存放，内容可以重复执行（幂等）。

## 自测（完成前必须做）
- 在空库上执行一遍完整的迁移（up），确认能成功。
- 执行一次回滚（down）再重新 up，确认能成功。
- 运行数据访问层的测试。

## 汇报
列出：迁移文件、表和索引的变化、回滚方式、对其它层的影响（例如需要重新生成 ORM 类型）。
